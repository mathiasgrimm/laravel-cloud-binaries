RSA-MD license
==============

Message-Digest Algorithm, by way of qpdf's native crypto provider
(libqpdf/MD5_native.cc). That file states it "is derived from the reference
algorithm for MD5 as given in RFC 1321", and carries the notice reproduced
below in full.

Note that upstream qpdf's NOTICE.md does not mention this component; this file
and the qpdf section of THIRD-PARTY-NOTICES.md carry the required
identification instead.
